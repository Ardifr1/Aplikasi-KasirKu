# Kasir App

Aplikasi kasir sederhana berbasis web

## ✨ Fitur Utama
- Login & Register dengan validasi input
- Dashboard transaksi harian
- Manajemen produk (CRUD)
- Transaksi kasir dengan metode pembayaran
- Laporan penjualan (filter & ekspor)
- Pengaturan profil dan sistem

## 🛠️ Teknologi
- Frontend: HTML, CSS, JavaScript
- Backend: PHP/Laravel (opsional)
- Database: MySQL
